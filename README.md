### Raindrop — my Unity game foundation

**Raindrop** is a private, modular Unity toolkit that I design and maintain to avoid rebuilding the same production infrastructure for every mobile game.

It separates shared services from game-specific mechanics, art, and content. The portfolio showcases its architecture and practical purpose, including:

- **Scene and level flow:** Bootstrap, additive scene transitions, progression, win/fail/revive flows, and lifecycle handling.
- **Core services:** Object pooling, audio, mobile haptics, saving, economy, events, and diagnostics.
- **Architecture:** VContainer-based dependency injection, with UniTask and DOTween in development workflows.
- **Editor tooling:** Project setup, validation, templates, quick actions, and repeatable production utilities.
- **Capture Studio v2 (in development):** Unity Editor screenshot and video capture workflows for store assets and marketing, with configurable HUD visibility and visual finger overlays.

Raindrop is an internal production toolkit, **not an open-source package distributed by this portfolio repository**.
